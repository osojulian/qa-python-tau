# QA Automation & Python Learning Path

Repositorio de prácticas y ejercicios desarrollados durante la ruta de aprendizaje **Python Programming** en **Test Automation University (TAU)**.

## 📌 Contenido
- **Fundamentos de Python:** Variables, operadores sintácticos y estructuras de control (`if`, `for`, `while`).
- **Estructuras de Datos:** Listas, diccionarios y manipulación de datos.
- **Funciones:** Parámetros posicionales, `*args` y `**kwargs`.
- **POO Basico:** Clases, constructores (`__init__`) y métodos de instancia.

## 🚀 Cómo ejecutar
1. Clonar repositorio: `git clone https://github.com/osojulian/qa-python-tau`
2. Crear entorno virtual: `python -m venv .venv`
3. Activar e instalar dependencias.
